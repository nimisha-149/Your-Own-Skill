# Project 16 – Your Own Skill
Created by: Nimisha R. | Department: AIML

## Skill chosen
`/viva` – an AI viva-practice skill that asks questions from study notes one at a time, evaluates answers, scores them out of 5, and provides a final revision summary.

## Files
- `your-own-skill/SKILL.md` – reusable skill instructions
- `test-cases.md` – three input scenarios and expected behaviour
- `comparison.md` – baseline vs skill-enabled comparison
- `prompts.md` – prompts used to create and test the skill
- `PROJECT_REPORT.pdf` – project report

## How to use
This is a portable skill definition. Add/import the `your-own-skill` folder into an agent platform that supports reusable skills. If your platform has a skill creator, create a skill named `viva` and paste the contents of `SKILL.md`. Then start a fresh session and attach your notes before typing `/viva`.

## Important
The skill definition is prepared, but the actual fresh-session tests must be run in the agent platform you use. The test cases in this package are a test plan, not fabricated test results.
