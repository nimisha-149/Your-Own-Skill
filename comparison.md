# Baseline vs Skill-Enabled Comparison

## Same task
Prepare for a viva using a student's uploaded chapter notes.

## Without the skill
- The user must repeatedly explain the preferred viva format.
- The assistant may ask several questions together unless instructed otherwise.
- Scoring and final revision feedback may vary between sessions.
- The user may need to repeat the scoring rubric.

## With the /viva skill
- A short `/viva` command starts the defined workflow.
- Questions are asked one at a time.
- Every answer is scored using the same 0–5 rubric.
- Feedback includes correct points, gaps, a model answer, and source location when available.
- A final score and revision plan are provided.

## What to demonstrate
Run the same notes and prompt once without the skill and once with the skill. Compare the number of questions per turn, consistency of scoring, use of note references, and quality of final revision advice. Insert screenshots and actual observations in the final submission.
